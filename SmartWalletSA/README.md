# Smart Wallet SA

Smart Wallet SA is an enterprise fintech wallet system built using:

- ASP.NET Core Web API
- Angular
- Entity Framework Core
- SQL Server

## Features

- User authentication
- Wallet management
- Deposits and withdrawals
- Money transfers
- Transaction history
- Financial analytics dashboard

## Tech Stack

### Backend
- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server

### Frontend
- Angular
- TypeScript
- Bootstrap
